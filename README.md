# StockFlow MVP

A multi-tenant SaaS Inventory Management System built with React (Vite) and FastAPI.

- **Live App:** https://stockflow-mvp-omega.vercel.app
- **API Docs:** https://stockflow-mvp-2t5v.onrender.com/docs

## Local Setup
- **Backend:** `cd backend && pip install -r requirements.txt && uvicorn main:app --reload`
- **Frontend:** `cd frontend && npm install && npm run dev`
